## 一、这套文档是什么

`docs/` 下的 12 份文档是**设计文档**（世界观、机制、数值、美术、平衡）。

`docs/tech/` 下的这 8 份文档是**实现文档**：把设计文档里的每一条规则，落到**具体的类名、方法签名、JSON 结构、配置项**上。

**所有技术结论的来源**（按可信度排序）：

| 来源 | 可信度 | 说明 |
|---|---|---|
| `javap` 反编译 + 常量池解析 | ⭐⭐⭐ 实测 | 直接读 `.class` 文件，方法签名/常量值 100% 准确 |
| ISS 实装 JSON 文件 | ⭐⭐⭐ 实测 | `data/irons_spellbooks/**/*.json` 逐字引用 |
| 参考项目源码 | ⭐⭐⭐ 已编译验证 | `D:\桌面\1.20.1forge模组开发`，已成功构建并发布 |
| 推断 | ⭐⭐ 待验证 | 标注了 ⚠️，M1 阶段必须实测 |

**文档里凡是写"实测"的，都是我读过字节码/JSON 原文后写下的，不是从网上抄的模板。**

## 五、五条最重要的结论

如果时间只够读五句话，读这五句：

### 1. 第三方模组**可以**注册新学派（已验证）

ISS 的 `SchoolRegistry.SCHOOL_REGISTRY_KEY` 是**公开**的自定义注册表，标准 `DeferredRegister` 即可写入。
**但**必须在 `FMLCommonSetupEvent` 里用 `event.enqueueWork(...)` 注册，否则会有竞态（`07` §坑 #6）。

### 2. 卷轴和法术书**零反射**就能做（已验证）

`ISpellContainer` 在 `api` 包，所有静态工厂都是 `public static`。创建卷轴只需一行：

```java
ISpellContainer.createScrollContainer(spell, level, stack);
```

### 3. 音效**不用做**，引用 ISS 的就行（已验证）

`sounds.json` 里的 `sounds` 是**资源路径**，可以跨命名空间引用。
忆海定义了 **39 个音效事件**，全部指向 `irons_spellbooks:` 下已存在的 265 个 `.ogg` 之一。
`tools/check_sounds.py` 实测 **42 条引用全部有效，0 失效**。
（同时规避了 ISS `All Rights Reserved` 的再分发风险。）

### 4. 卷轴贴图是**机械改色**，可以脚本生成（已验证）

10 张官方卷轴贴图的 **alpha 掩码逐像素零差异**（都是 137 个不透明像素），
底图恰好 **11 色**，每张学派贴图都是对这 11 色的严格 1:1 替换。
`tools/gen_scroll_texture.py` 可精确生成忆海版本，**不用画图**。

### 5. 忆海的"临时遗忘"**不再是风险**（v1.7 推翻）

~~`GoalSelector.removeGoal()` 是**永久**的，无法撤销。这影响 7 个 P0 生物的"临时失忆"效果。~~
**已实测推翻**（2026-09-16）：`Mob.goalSelector` / `targetSelector` 在 1.20.1 Forge 下是
**public** 的（Forge AccessTransformer 提升），`addGoal()` / `removeGoal()` 都能直接调。
所以"临时遗忘"就是 **移除 + 记录 + 到期恢复**，**不需要 Mixin**。
细节见 `03` §7.2/§7.3（已更正）与 `oblivion/AbilityMap`。

## 五·五、配套工具（`tools/`）

| 工具 | 用途 | 用法 |
|---|---|---|
| `gen_scroll_texture.py` | 卷轴贴图精确改色 / 符文渐变映射 / 护甲色相偏移 | `python gen_scroll_texture.py --help` |
| `gen_mnemosyne_art.py` | **30 张贴图程序绘制**（物品 6 / 护甲图层 2 / 方块 4 / 法术图标 18），含逐张校验与拼版预览 | `--all` / `--check` / `--contact-sheet <path>` |
| `check_sounds.py` | 校验忆海 `sounds.json` 对 ISS 音频的引用是否有效 | `python check_sounds.py` |
| **`check_resources.py`** ⭐ | **跨工作流资源一致性校验**（7 项）：模型→贴图 / 法术 id 三处一致 / 双语键集 / `sounds.json` schema / `worldgen` 注册表引用 / 能力·特性 id 一致 / 孤儿贴图。**专门抓 `./gradlew build` 一个都不报的静默失败** | `python tools/check_resources.py [--verbose] [--pending-detail]` |
| `check_ability_map.py` | 校验 `AbilityMap.RULES` 有序首次命中表的正确性（WS-E 自带） | `python tools/check_ability_map.py` |

**环境**：需要 Python 3 + Pillow（已装在 `~/.workbuddy-ai/binaries/python/envs/default`）。

> ⭐ **提交前跑一次 `check_resources.py`。** 它覆盖的失败模式（紫黑格 / 法术静默无声 /
> 存档加载不了 / 空箱子 / 遗迹生成空气 / 中文夹英文）**没有一个**会被 `./gradlew build` 报出来。
> 退出码 0 = 无真缺陷；`pending` 条目是**已知排期中的欠账**，刻意不阻塞退出码 ——
> 校验器永远红着就等于没有校验器。
