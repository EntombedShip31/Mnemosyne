## 零、设计规则（官方 ISS 实测）

| 规则 | 内容 |
|---|---|
| **法力公式** | `法力(L) = base + perLevel × (L−1)`，`perLevel = 0.2 × base`（官方中位数） |
| **满级锚定法** | 先定「满级法力目标」，再反推 `base = 目标 / (1 + 0.2×(N−1))` |
| **每级增量比** | 全部落在 0.176 ~ 0.206，中位 **0.200**（官方中位数） |
| **满级法力区间** | 29 ~ 197，全部落在官方全局区间（10 ~ 800）内 |
| **最大等级调色板** | 只用 `{1, 3, 4, 5, 6, 8, 10}`（官方 113 个法术实际用到的值，没有 2 / 7 / 9） |
| **冷却** | 固定值，不随等级变（与官方一致） |
| **稀有度** | 不是法术的固定属性，由**等级在自身区间里的位置**推导：30% / 25% / 20% / 15% / 10%；**最高级必定 Legendary**；起始档高的法术把剩余档位权重**按比例重新分配** |
| **1 级法术** | 官方硬规则：**必定是 Legendary**，且官方 7 个 1 级法术全是昂贵的一次性工具 |
