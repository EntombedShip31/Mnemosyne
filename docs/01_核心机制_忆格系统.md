# 核心机制 · 忆格系统（Engram）

> 本文是记忆流派的**地基文档**。所有法术、装备、数值都建立在这套系统之上。
> 上级文档：[README 总览](README.md)　｜　相关文档：[02 遗忘系统](02_核心机制_遗忘与能力映射.md)、[07 装备与道具](07_装备与道具.md)

---

## 一、什么是忆格

**忆格（Engram）**是玩家身上用来存储"记忆"的容器。

### 世界观解释

忆者（Mnemosyne 学派的古人）相信：**记忆是唯一真实的财富**。肉体会腐烂，装备会锈蚀，唯有经历过的事情永远属于你——前提是你能把它记住。

他们在自己的意识中开辟出若干个"格子"，把重要的事情装进去，需要时再取出来。格子的数量取决于意志的强度，而不是天赋。这就是忆格。

### 玩家感知

玩家第一次解锁学派后，会在**法力条的正下方**看到一排空心的小方格（默认 3 个）。这就是忆格。

- 空格显示为半透明的靛蓝色轮廓
- 写入后显示对应记忆类型的图标 + 剩余时间环形进度条
- 释放后格子恢复空心，并播放一次破碎音效

---

## 二、忆格数量

| 来源 | 数量 | 说明 |
|---|---|---|
| 基础 | **3** | 解锁学派即获得 |
| 忆者法袍 2 件套 | **+1** | 累计 4 |
| 忆者法袍 4 件套 | **+1** | 累计 5 |
| 法术「碎忆」 | **+1（临时）** | 持续 15 秒 |
| 法术「忆格扩张」 | **+2（临时）** | 持续 30 秒 |
| 法术「忆海」领域内 | **+3（临时）** | 领域持续 8 秒 |

### 硬性上限

- **常驻忆格上限为 5**（基础 3 + 套装 2）。这是硬性设计红线，任何途径都不能突破常驻上限。
- **临时忆格可以突破上限**。例如穿着全套套装（5 格）再施放「忆格扩张」，会短暂拥有 7 格。
- 临时忆格在到期后**若为空则直接消失**；**若仍存有记忆，则该记忆一并消散**（玩家需要提前释放，这是风险）。

> **设计意图**：常驻上限固定，是为了让"取舍"永远成立。如果忆格能无限堆，共鸣机制就会退化成纯数值堆叠，流派的灵魂就没了。

## 三、三种记忆

三种记忆**共享同一批忆格**。这是流派最重要的设计——玩家永远在"我该存什么"这个问题上做决策。

### 3.1 术忆（Spell Memory）

**写入什么**：你**上一次成功施放的法术**。

| 项 | 规则 |
|---|---|
| 写入法术 | 「写入 · 术忆」 |
| 记录内容 | 法术 ID、法术等级、施法者当时的相关属性 |
| 有效期 | 120 秒 |
| 释放效果 | **免费瞬发该法术**：消耗 0 法力、不进入冷却 |
| 释放威力 | 原法术的 **70%**（受共鸣加成提升） |
| 释放施法时间 | 原法术施法时间的 **50%** |

**关键规则**：

- 记录的是**法术本身**，不是"那次施放的位置/目标"。释放时需要重新指定目标。
- **可以存入同一个法术多次**。占两个忆格存两个大招是合法且常见的打法。
- 写入时记录的是**当时的法术等级**。如果你在写入后升级了该法术，释放时仍按旧等级计算（"记忆是当时的记忆"）。
- 长吟与持续类法术（Long / Continuous）写入时只记录"法术本身"，释放时会重新完整引导一次。
- **不能写入**：写入类法术自身、忆格相关的元法术（「忆格扩张」「复诵」「既视感」）。

**设计意图**：术忆是"连招"的核心。玩家的爽点在于——先用一个消耗巨大的终极法术，把它存起来，然后在共鸣满格时免费再来一发。

---

### 3.2 质忆（Trait Memory）

**写入什么**：你**接触到的生物的一个特性**。

| 项 | 规则 |
|---|---|
| 写入法术 | 「写入 · 质忆」 |
| 触发条件 | 施法时，视线内最近的生物（8 格内） |
| 记录内容 | 该生物**可被窃取特性列表**中的**随机一项** |
| 有效期 | 120 秒 |
| 释放效果 | 你获得该特性，持续 **30 秒** |
| 释放威力 | 持续时间受共鸣加成延长（每占用 1 格 +5 秒） |

**关键规则**：

- 写入是**随机的**——如果目标有多个可窃取特性，你拿到哪一个不确定。想要指定特性，需要反复尝试或使用「记忆掠夺」。
- 完整的可窃取特性清单见 [02 文档 §四](02_核心机制_遗忘与能力映射.md)。
- 特性在释放时**覆盖**你当前的状态（例如你已经有夜视，再获得夜视则刷新时长）。
- **BOSS 与部分精英生物不可窃取**（详见 02 文档）。
- 释放后忆格清空，特性倒计时独立计算。

**设计意图**：质忆是"适应"的核心。下地狱前偷一个火焰免疫，打末地前偷一个缓降或传送——它奖励的是**事前准备**，而不是临场反应。

---

### 3.3 痛忆（Pain Memory）

**写入什么**：你**接下来一段时间内受到的全部伤害**。

| 项 | 规则 |
|---|---|
| 写入法术 | 「写入 · 痛忆」 |
| 记录窗口 | 施放后 **6 秒** |
| 记录内容 | 期间你受到的所有伤害的**总和**（含各种伤害类型） |
| 伤害上限 | 你**最大生命值的 60%**（超出部分不计入） |
| 有效期 | 120 秒（从记录窗口结束时开始计算） |
| 释放效果 | 对目标造成**等量伤害**，**无视护甲** |
| 释放威力 | 受共鸣加成提升 |

**关键规则**：

- 记录窗口内**受到的伤害是真实发生的**——痛忆不会减免或转移伤害，它只是"记账"。
- 伤害上限的存在是为了防止"故意站在岩浆里刷一个秒杀伤害"的滥用。
- **自杀式伤害不计入**（例如 /kill、虚空伤害、玩家自己的自伤法术）。
- 释放时无视护甲，但**受目标的记忆法术抗性影响**（`memory_magic_resist` 可以减少这部分伤害）。
- 如果记录窗口结束时伤害为 0，忆格保持为空（不产生空记忆）。

**设计意图**：痛忆是流派唯一的高风险反打手段。它鼓励玩家"主动吃伤害换爆发"，把生存压力转化为进攻资源。这是这个流派最有赌徒气质的部分。

## 四、共鸣（Resonance）

**忆格占用越多，释放威力越强。**

| 已占用忆格数 | 释放威力加成 |
|---|---|
| 1 格 | +0% |
| 2 格 | +20% |
| 3 格 | +40% |
| 4 格 | +60% |
| 5 格 | +80% |

**忆者法袍 4 件套**将每格加成从 +20% 提升至 **+25%**（5 格时可达 +100%）。

### 代价

忆格被占用期间，玩家承受以下惩罚：

| 已占用忆格数 | 施法速度 | 法力消耗 |
|---|---|---|
| 1 格 | -8% | +10% |
| 2 格 | -16% | +20% |
| 3 格 | -24% | +30% |
| 4 格 | -32% | +40% |
| 5 格 | -40% | +50% |

### 核心决策

这套机制创造了一个清晰的两难：

- **空着忆格**：施法快、省蓝，但释放毫无威力。适合游走、骚扰、逃跑。
- **囤满忆格**：释放爆炸，但施法慢 40%、蓝耗高 50%，还要赌 120 秒内不被清空。适合决战场合。

> **高手玩法**：在战斗前囤满，开战时先用「复诵」把最强的两个记忆连续释放（不消耗），再逐一清空——在惩罚生效前把爆发打完。

## 五、记忆腐坏（Decay）

记忆不是永久的。

| 规则 | 内容 |
|---|---|
| 基础有效期 | **120 秒**（2 分钟） |
| 法袍 3 件套加成 | 有效期延长至 **180 秒** |
| 计时起点 | 写入成功的那一刻 |
| 视觉提示 | ⚠️ 2026-09-17 起**不再有忆格 HUD**（自定义 GUI 已删除）。状态变化时走动作栏一行字 `忆格 2 / 3` + `hud.engram.fill` 音效；随时用 `/mnemosyne engrams` 主动查询。见 `docs/09` §五 |
| 过期效果 | 忆格清空，播放"玻璃碎裂"音效，玩家视野边缘闪过一次靛蓝色波纹 |

### 特殊情况

- **跨维度**：进入下界/末地**不会**暂停计时。记忆跟着你走，但时间也在流逝。
- **退出游戏**：离线时间**不计入**腐坏（避免玩家上线发现全空了）。登录后倒计时从上次离线时的剩余时间继续。
- **死亡**：**所有忆格立即清空**（"死亡即失忆"）。这是流派最大的风险点，也是平衡的关键。

> **设计意图**：腐坏机制的存在，是为了防止"囤满 5 格然后永远不释放"。记忆是有保质期的——这既是世界观，也是玩法约束。

## 六、忆格的完整操作流程

```
① 写入 ──→ ② 持有 ──→ ③ 释放 ──→ ④ 清空
   ↑                        │
   └──── 或主动丢弃 ─────────┘
```

### ① 写入

1. 施放对应的「写入」法术（术忆 / 质忆 / 痛忆）。
2. 系统检查是否存在**空忆格**。
3. 若无空忆格 → 法术失败，提示"忆格已满"，**法力照常消耗**（这是惩罚，逼玩家管理格子）。
4. 若有空忆格 → 完成写入，忆格填充，播放"抽取"粒子（一缕发光丝线从目标/自身飞入胸口）。
5. 写入的施法时间：术忆 0.5 秒 / 质忆 0.8 秒 / 痛忆 0.3 秒（法袍 3 件套可再减 30%）。

### ② 持有

- 忆格保持填充状态，倒计时进行中。
- 玩家无法在持有期间"更换"忆格内容——必须先丢弃或释放。

### ③ 释放

释放有两种方式：

| 方式 | 说明 |
|---|---|
| **逐一释放** | 默认键位，释放**最早写入**的那个忆格（先进先出）。适合快速清空 |
| **指定释放** | 需要装备「忆晶权杖」或使用「复诵」法术，可以选择任意一个忆格释放 |

- 释放**不消耗法力**、**不进入冷却**（但仍受铁魔法的全局施法间隔限制）。
- 释放有 0.3 秒的固定施法动作（举手 → 忆格破碎 → 效果触发）。
- 释放会触发**共鸣加成**（按释放瞬间的占用格数计算）。

### ④ 清空

- 正常释放后忆格立即清空。
- 使用「复诵」释放时，忆格**保留**（可连续释放同一个记忆）。
- 使用「既视感」时，所有被复现的法术**不消耗忆格**（既视感复现的是"施法记录"，不是忆格内容）。

### 主动丢弃

- 长按释放键 1 秒 → 丢弃**指定**忆格，忆格清空，播放一次轻微的"叹气"音效。
- 丢弃无消耗、无冷却，但有 0.5 秒动作。
- 用途：腾出格子去装更重要的记忆。

## 七、边界情况与规则澄清

| 问题 | 规则 |
|---|---|
| 能否同时存两个相同的法术？ | **可以**。占两个忆格存两个大招是常见打法 |
| 写入时没有目标怎么办？ | 术忆不需要目标；质忆若无目标则写入失败但**不消耗法力**；痛忆不需要目标 |
| 忆格数据在多人服务器会共享吗？ | **不会**。忆格是每个玩家独立的个人数据 |
| 其他玩家能看到我的忆格吗？ | 不能。忆格数据只在服务端玩家 NBT 里、不下发客户端，别人看不到；但**释放时的破碎粒子对所有玩家可见** |
| 能否存入其他玩家施放的法术？ | **不能**（术忆只记录自己）。「记忆掠夺」也不能对玩家使用 |
| 能否对玩家使用遗忘？ | **不能**。遗忘类法术对玩家完全无效（保护 PVP 体验） |
| 忆格在创造模式有区别吗？ | 创造模式下忆格同样生效，但腐坏计时暂停（方便测试） |
| 忆格会被其他模组清除吗？ | 忆格存于玩家数据，跨维度、跨存档传送均保留；但被其他模组强制重置玩家数据时会丢失 |
| 临时忆格到期时里面有记忆怎么办？ | 记忆一并消散。玩家需提前释放（这是「忆格扩张」的风险设计） |
| 共鸣加成什么时候结算？ | **释放瞬间**结算。先释放一个记忆（此时占 3 格 → +40%），释放后变 2 格，下一次释放只算 +20% |
| 重复释放同一个记忆（复诵）时共鸣怎么算？ | 每次都按释放瞬间的占用格数重新计算。由于忆格未清空，第二次释放时占用格数不变，加成相同 |

## 八、玩家上手路径（新手引导设计）

| 阶段 | 玩家学会的事 | 引导方式 |
|---|---|---|
| 刚解锁 | 忆格是什么、怎么写入 | 首次获得学派时，忆碑播放一段失落记忆（教学文本） |
| 前 30 分钟 | 术忆怎么用、共鸣是什么 | 忆矢/碎忆的提示文本 |
| 1 小时后 | 质忆的价值、该偷什么 | 第一次遇到烈焰人时的提示（"它的火焰免疫似乎可以被记住"） |
| 10 小时后 | 痛忆的赌徒玩法、遗忘的战术价值 | 无引导，玩家自己发现 |

> **设计原则**：**永远不要用文字教程解释"遗忘"**。让玩家自己在监守者身上发现"我居然能让它闭嘴"，那一刻的震撼胜过任何教程。

## 九、常见误设计（不要这样做）

| 想法 | 为什么不行 |
|---|---|
| 让忆格无限堆叠 | 共鸣退化为纯数值，取舍消失，流派灵魂死亡 |
| 取消记忆腐坏 | 玩家会囤满后永远不释放，"银行"变成"仓库" |
| 让术忆 100% 威力 | 免费再来一发等于翻倍 DPS，必须打折（70%） |
| 让痛忆无上限 | 玩家会站在岩浆里刷一个秒杀伤害，破坏平衡（上限 60% 最大生命） |
| 死亡不清空忆格 | 死亡失去意义，玩家会无脑囤 |
| 让遗忘对玩家生效 | PVP 会变成互相禁言，体验灾难 |
