## 一、视觉识别原则

### 核心问题：怎么让玩家一眼认出"这是记忆流派"

铁魔法现有 9 个学派，色板已经被大量占用。记忆流派的视觉必须满足三条：

| 原则 | 说明 |
|---|---|
| **① 色彩不撞车** | 不能和末影（青紫）、邪术（深紫黑）混淆 |
| **② 形状有签名** | 必须有一个反复出现的图形母题 |
| **③ 动势是"碎裂 / 抽取"** | 不是"爆炸 / 燃烧 / 冻结"，而是**向内收拢、向外碎裂** |

### 图形母题：碎片与环形

记忆流派有两个反复出现的图形：

| 母题 | 用途 |
|---|---|
| **碎片（Shard）** | 所有"记忆"的具象化——忆晶、粒子、法术投射物、忆格图标 |
| **环形（Ring）** | 所有"认知过载"与"领域"的具象化——层数光环、诅咒领域、忆海 |

**记忆 = 碎片。认知 = 环形。** 这两个母题贯穿全部美术资源。

### 动势规则

| 动作 | 动势方向 | 含义 |
|---|---|---|
| 写入记忆 | **由外向内**（丝线飞入胸口） | 收集 |
| 释放记忆 | **由内向外**（碎片炸开） | 支出 |
| 遗忘 | **向下坠落**（符号崩塌） | 流失 |
| 认知过载 | **环绕旋转** | 累积 |
| 忆海 | **向上飘浮**（书页、文字） | 展开 |

> **重要**：记忆流派的粒子**不要有火焰、冰霜、电弧的质感**。它应该是**玻璃、水晶、纸、墨**的质感。

## 二、配色系统

### 2.1 主色板

| 用途 | 颜色 | 色值 | 说明 |
|---|---|---|---|
| 主色（靛蓝） | 深靛蓝 | `#534AB7` | 忆晶、术忆、主粒子 |
| 主色浅 | 浅靛蓝 | `#AFA9EC` | 高光、渐变亮部 |
| 主色深 | 暗靛蓝 | `#26215C` | 阴影、暗部 |
| 辅色（品红） | 品红 | `#D4537E` | 质忆、认知过载、强调 |
| 辅色浅 | 浅品红 | `#ED93B1` | 高光 |
| 辅色深 | 暗品红 | `#4B1528` | 暗部 |
| 中性 | 米白 | `#F1EFE8` | 文字、书页 |
| 中性 | 石灰 | `#888780` | 石制建筑 |

### 2.2 三种记忆的颜色编码

**这是最重要的视觉规则**——玩家应该能通过颜色一眼看出忆格里存的是什么：

| 记忆类型 | 颜色 | 色值 |
|---|---|---|
| **术忆** | 靛蓝 | `#534AB7` |
| **质忆** | 品红 | `#D4537E` |
| **痛忆** | 深紫 | `#3C3489` |
| 空忆格 | 半透明靛蓝轮廓 | `#534AB7` @ 30% |

> **记忆掠夺的永久记忆**用**带金色描边**的对应颜色，与普通记忆区分。

### 2.3 禁用的颜色

| 禁用 | 原因 |
|---|---|
| 青紫色（末影的色板） | 会和末影混淆 |
| 纯黑 / 深紫黑（邪术的色板） | 会和邪术混淆 |
| 亮蓝紫（雷的色板） | 会和雷混淆 |
| 任何火焰橙红 | 会和火混淆 |

## 三、粒子效果清单

| 场景 | 粒子 | 运动方式 | 颜色 |
|---|---|---|---|
| **忆矢飞行** | 拖尾碎片（3-5 个/秒） | 沿飞行轨迹散落 | 靛蓝 |
| **忆矢命中** | 碎片爆发（8-12 个） | 向外炸开 | 靛蓝 → 品红 |
| **认知过载（每层）** | 环绕光环（1 道/层） | 绕目标头顶旋转 | 品红 |
| **认知过载满 5 层** | 额外外圈 | 反向旋转 | 品红 + 金色 |
| **写入记忆** | 抽取丝线（1 条） | 从目标/自身飞向胸口 | 靛蓝 |
| **写入完成** | 忆格闪烁 | 胸口一次脉冲 | 对应记忆色 |
| **释放记忆** | 碎片扩散（15-20 个） | 从胸口向外炸开 | 对应记忆色 |
| **记忆腐坏** | 碎片下落 | 向下飘落消失 | 靛蓝 → 透明 |
| **遗忘（目标）** | 碎裂符号 | 目标头顶符号崩解 | 品红 |
| **失忆（目标）** | 问号状粒子 | 缓慢飘浮 | 浅靛蓝 |
| **遗忘诅咒领域** | 符文圆阵 + 下落碎片 | 圆阵旋转，碎片向下 | 靛蓝 + 品红 |
| **集体遗忘** | 巨大波纹（半径 8 格） | 向外扩散一圈 | 靛蓝 |
| **走马灯复现** | 快速闪过的影像碎片 | 从目标飞向施法者 | 品红 |
| **既视感** | 屏幕边缘向内挤压的波纹 | 由外向内 | 靛蓝 |
| **忆海领域** | 巨大书页纹理 + 上浮文字碎片 | 书页静止，碎片向上 | 靛蓝 → 品红渐变 |
| **忆海结束** | 水晶碎裂（大量碎片） | 向外炸开 | 靛蓝 + 品红 |
| **千忆归一吟唱** | 环绕的忆晶碎片（逐渐增多） | 绕施法者旋转并收拢 | 三种记忆色混合 |
| **千忆归一释放** | 多道光束 | 射向目标 | 每格一种颜色 |
| **千忆归一命中** | 走马灯式影像闪回 | 快速闪过 | 全彩 |
| **忆晶簇** | 环境粒子（缓慢上浮） | 向上飘 | 靛蓝 |
| **忆碑（未读）** | 流动光纹 | 沿表面流动 | 靛蓝 |
| **忆碑（已读）** | 暗淡光纹 | 缓慢流动 | 暗品红 |

## 四、施法动画

### 4.1 通用施法动作

| 阶段 | 动作 |
|---|---|
| **起手** | 手部浮现一个**旋转的忆晶虚影**（0.2 秒内淡入） |
| **施放** | 忆晶虚影爆开，化为粒子 |
| **收招** | 手部留下一圈**向内塌缩的环形符文**（0.3 秒后消失） |

### 4.2 特殊动画

| 法术 | 动画 |
|---|---|
| **写入类** | 手部虚影不是爆开，而是**向内收拢**成一个点（"装进去"的感觉） |
| **释放忆格** | 双手向前推出，胸口忆格破碎，碎片沿手臂流向前方 |
| **千忆归一** | 双手上举，全身被碎片包裹，碎片随吟唱进度逐格亮起；释放时双手前推 |
| **忆海** | 双手张开，脚下展开符文圆阵，随后向上抬起 |
| **集体遗忘** | 单手按地，波纹从脚下扩散 |
| **走马灯** | 单手前指，手指间有碎片闪烁 |

### 4.3 施法时的角色姿态

- 记忆流派的施法姿态应该**偏"安静"**——不要有大幅度的挥臂。
- 参考：**翻书、按太阳穴、手指轻点**。
- 唯一例外是三个长吟法术（记忆掠夺、忆海、千忆归一），它们需要更夸张的姿态（吟唱期间无法移动）。

> **设计意图**：记忆流派的战斗节奏是"安静地计算，然后爆发"。姿态应该反映这种气质。

## 五、忆格状态反馈（**已废弃自定义 HUD**）

> ⚠️ **2026-09-17 重大变更**：本节原先是一份完整的「忆格 HUD」设计
> （法力条下方的忆格条、环形倒计时、共鸣指示器、HUD 开关配置等）。
> **该自定义 GUI 已被彻底删除**，包括代码（`EngramHudOverlay` / `S2CSyncEngramsPacket`
> / `NetworkHandler`）、资源与文档描述。
>
> **决策理由**：忆格条与本模组已有的原版渠道重复，且需要一整套
> 「客户端缓存 + S2C 同步包 + 脏标记」基础设施来喂它 ——
> 那套基础设施本身就是一类 bug 的来源（数据不同步、登出串数据、
> 客户端与服务端两套读取路径）。删掉之后：少一个 GUI、少一套网络、少一类不同步。
>
> **新的反馈原则**：忆格状态**不常驻显示**，只在**发生变化时**用原版渠道提示一次。
> 这符合本模组"记忆是稀缺的、需要主动管理"的设计基调 ——
> 常驻的血条式 UI 会让玩家把忆格当成"资源条"而不是"记忆"。

### 5.1 反馈渠道（全部是原版渠道，不新增 GUI）

| 时机 | 渠道 | 内容 |
|---|---|---|
| 写入 / 释放 / 腐坏 / 到期 | **动作栏**（物品栏上方） | `忆格 2 / 3` |
| 写入 / 释放 / 腐坏 / 到期 | 音效 | `hud.engram.fill` |
| 死亡清空 | **聊天栏** | `你死了 —— 全部忆格已消散` |
| 法术失败（无目标） | 动作栏 | `没有可作用的目标` |
| 法术失败（BOSS 免疫） | 动作栏 | `目标免疫「剥夺」` |
| 法术失败（忆格满） | 动作栏 | `忆格已满，无法写入` |

### 5.2 为什么用动作栏而不是聊天栏

- 动作栏在物品栏上方，施法时玩家视线本来就在屏幕中央附近，**不挡视线**；
- 忆格变动很频繁（每次编码 / 释放 / 腐坏都变），走聊天栏会把玩家的聊天记录冲掉。

### 5.3 为什么不用状态效果图标

原版状态效果图标（右上角）本来是一个候选渠道，但忆格**不是 debuff**，
而且它有 3~5 个槽位、每个槽位内容不同（法术记忆 / 特性记忆 / 痛苦记忆），
原版效果图标表达不了"第 2 格装了什么"。

### 5.4 主动查询

玩家想主动看忆格时，用指令：

```
/mnemosyne engrams
```

权限等级 0（普通玩家也能用）—— 这是忆格 GUI 删除后玩家查看自己忆格状态的**唯一途径**，
所以刻意不要求 OP。

### 5.5 认知过载指示

**不在玩家 UI 上显示**——认知过载是**目标身上的状态**，显示在目标头顶（环绕光环）。

> 理由：玩家的注意力应该在敌人身上，而不是自己的 UI 上。让玩家的眼睛盯着敌人头顶的光环，是刻意的引导。

## 六、音效清单

### 6.1 施法音效

| 场景 | 音效描述 | 时长 |
|---|---|---|
| 忆矢发射 | 水晶轻响 + 短促气流 | 0.3s |
| 忆矢命中 | 玻璃碎裂（轻微） | 0.4s |
| 写入记忆 | 磁带倒带的嘶嘶声（短） | 0.5s |
| 写入完成 | 一声轻微的"叮"（水晶共鸣） | 0.3s |
| 释放记忆 | 玻璃碎裂 + 一声低沉共鸣 | 0.6s |
| 遗忘（目标） | 低语（2-3 层人声叠加） | 0.8s |
| 失忆（目标） | 低语 + 一声"叹息" | 1.0s |
| 走马灯 | 快速翻阅书页的沙沙声 | 0.6s |
| 认知崩坏 | 心跳声（加速）+ 一声炸裂 | 1.2s |
| 既视感 | 磁带倒带（长）+ 一次回声 | 1.0s |

### 6.2 环境音效

| 场景 | 音效描述 | 触发条件 |
|---|---|---|
| 忆格即将腐坏 | 极轻的低语（音量很低） | 忆格剩余 < 20 秒，每 5 秒一次 |
| 忆格腐坏 | 玻璃碎裂 | 忆格过期 |
| 靠近忆者遗迹 | 极轻的低语（音量随距离增加） | 距离 < 24 格 |
| 进入核心室 | 低语音量提升 + 一次水晶共鸣 | 进入核心室 |
| 忆碑交互 | 低语人声（8 秒）+ 反向混响 | 右键忆碑 |
| 忆碑解锁完成 | 水晶共鸣（明亮的"叮"） | 文本播放完毕 |

### 6.3 音效设计原则

| 原则 | 说明 |
|---|---|
| **以"玻璃/水晶"为主** | 避免使用火焰、雷声、冰裂的采样 |
| **低语是人声** | 不是合成音效，是**真实的、多层叠加的、听不清内容的人声** |
| **反向混响** | 忆碑与既视感的音效使用反向混响（暗示"时间倒流"） |
| **音量克制** | 记忆流派的音效整体音量应**低于**火/雷学派。它不喧闹 |
| **低频为主** | 钟摆、心跳、低语——用低频制造"沉稳"感 |

### 6.4 关于"低语"的特别说明

低语是记忆流派的**声音签名**。建议：

- 录制 **6-8 层不同的人声**（男女老少混合），每层说不同的内容（可以说忆碑文本，也可以说无意义的音节）。
- 混音时**降低清晰度**——玩家应该"感觉到有人在说话"，但听不清说什么。
- 音高略微失调（±5%），制造"不自然"的感觉。

> **这是整个流派最重要的一个音效**。玩家在社区里讨论记忆流派时，一定会提到"那个低语声"。

## 七、学派视觉对比表（确保不撞车）

| 学派 | 主色 | 粒子质感 | 动势 | 记忆流派的区分点 |
|---|---|---|---|---|
| 火 | 橙红 | 火焰、烟 | 向上燃烧 | 记忆是玻璃/水晶质感，不燃烧 |
| 冰 | 蓝白 | 冰晶、霜 | 凝结 | 记忆是靛蓝品红，不结霜 |
| 雷 | 亮蓝紫 | 电弧 | 跳跃 | 记忆没有电弧 |
| 神圣 | 金白 | 光芒 | 放射 | 记忆的光是冷光，不是金光 |
| 末影 | 青紫 | 紫色传送粒子 | 闪烁 | **最需要区分的**：末影是青紫，记忆是靛蓝+品红 |
| 血 | 深红 | 血滴 | 滴落 | 完全不同 |
| 咒法 | 翠绿 | 魔法粉尘 | 旋转 | 完全不同 |
| 自然 | 黄绿 | 树叶、孢子 | 生长 | 完全不同 |
| 邪术 | 深紫黑 | 虚空、触手 | 扭曲 | **第二需要区分的**：邪术近黑，记忆是明亮的靛蓝 |
| **记忆** | **靛蓝 + 品红** | **玻璃碎片、纸、墨** | **碎裂 / 抽取** | — |
