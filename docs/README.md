# 记忆 · 认知 Mnemosyne
## 流派设计文档集 · 总览与索引

> **主题句**："你所经历的一切，都可以成为武器。"
> **一句话定位**：战场上的**记忆银行家**。你不制造伤害，你**收集**伤害、**窃取**能力、**抹除**敌人的记忆。
> **文档版本**：v2.0　｜　**更新日期**：2026-09-15

## 一、为什么是"记忆"

铁魔法现有 9 大学派全部围绕**元素**或**生命**展开：火、冰、雷、神圣、末影、血、咒法、自然、邪术。它们共享同一套底层逻辑——**用法力换取一次效果**。

"记忆"是一个从未被触碰的维度，它天然提供三种别的流派给不了的东西：

| 玩家的诉求 | 其他流派的解法 | 记忆流派的解法 |
|---|---|---|
| 我想变强 | 提升数值、堆装备、堆层数 | **窃取敌人的能力，装到自己身上** |
| 我想削弱敌人 | 减抗、减防、挂负面状态 | **让敌人忘记怎么战斗** |
| 我想爆发 | 攒法力、攒层数、攒连击 | **把已经发生过的事情，再发生一次** |

这三条构成了流派的完整闭环，也是它的全部设计地基。

## 二、设计哲学（三条不可违背的原则）

**原则一：记忆必须是稀缺的。**
忆格只有 3 个，记忆只有 120 秒保质期。稀缺产生决策，决策产生乐趣。任何"让忆格无限扩张"的设计都会毁掉这个流派。

**原则二：这个流派不该有最高的伤害数字。**
它的价值在**信息**与**控制**，不在数值。如果一个玩家用记忆流派打出了全场最高伤害，说明其他流派出了问题。它应该让队友说"幸好有你在"，而不是"你输出好高"。

**原则三：BOSS 免疫"剥夺"。**
遗忘、窃取、复现对普通生物全部生效，但对 BOSS 完全免疫（改为数值化的削弱）。这不是偷懒，是保护整个游戏的战斗设计不被一个流派摧毁。

### 配色说明

铁魔法现有学派的色板已经被大量占用：火是橙红、冰是蓝白、雷是亮蓝紫、神圣是金白、末影是青紫、血是深红、咒法是翠绿、自然是黄绿、邪术是深紫近黑。

记忆流派使用**靛蓝 → 品红的虹彩渐变**。它既不属于冷色也不属于暖色，视觉上呈现"记忆碎片反光"的质感，与末影的青紫、邪术的深紫黑都能一眼区分。

## 四、三条支柱一览

```
① 忆格（收集）  →  ② 遗忘（削弱）  →  ③ 共鸣（爆发）
   收集三类记忆      剥夺敌人能力      囤积越多释放越强
```

- **① 忆格**：3 个格子，存三种记忆（术忆 / 质忆 / 痛忆），120 秒后腐坏。
- **② 遗忘**：三层级剥夺（遗忘 / 失忆 / 集体遗忘），让敌人忘记怎么战斗。
- **③ 共鸣**：占用越多，释放越强（+20%/格），代价是施法变慢、蓝耗变高。

详细规则见 `01` 与 `02`。

## 六、阅读建议

- **只想快速了解流派**：读 README + `01` + `03` 的总表。
- **要开始写策划/文案**：读 `04` ~ `06`（法术详解）+ `09`（美术音效）。
- **要开始做美术资源**：直接读 `09`。
- **要开始做建筑/地图**：直接读 `08`，实现时对照 `tech/06`。
- **要评估能不能做出来**：读 `11` + `02`（工作量最大的部分在映射表）。
- **要做数值平衡**：读 `10` + `03` 的曲线部分 + `tech/04` 的完整数值表。
- **要开始写代码**：读 `tech/00` → `tech/07` → `tech/02`，然后照 `tech/04` 填数值。
- **要并行开发（多会话）**：读 `tech/10` 全文，提示词从 `tech/11` 直接复制。
- **要做音效/贴图**：读 `tech/08` + `tech/09`（结论是都**不用从零做**）。
