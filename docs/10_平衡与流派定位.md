# 平衡与流派定位

> 本文定义记忆流派的强度定位、与现有九大学派的关系、可调参数与失衡预案。
> 上级文档：[README 总览](README.md)　｜　相关文档：[03 法术总表](03_法术_总表与设计准则.md)、[11 开发路线与风险](11_开发路线与风险.md)

---

## 一、定位表

| 维度 | 定位 | 说明 |
|---|---|---|
| **单体爆发** | 中低 | 只有 4 个直伤法术，且都需要前置条件 |
| **群体清场** | 中 | 遗忘诅咒 + 集体遗忘可以控制一片，但清场能力弱于火/雷 |
| **持续输出（DPS）** | **低** | 忆矢 DPS 约 4/秒，火学派火球约 5-6/秒 |
| **生存能力** | **高** | 质忆偷免疫、失忆脱战、痛忆反打 |
| **控制能力** | **极高** | 遗忘体系是全模组最强的"能力剥夺"手段 |
| **团队价值** | **极高** | 集体遗忘是唯一的"群体强制脱战"手段 |
| **操作难度** | **极高** | 需要同时管理忆格、层数、冷却、时机 |
| **成型速度** | 中 | 依赖找到忆者遗迹 |
| **上限强度** | **高** | 熟练玩家能打出极高的战术价值 |

### 一句话定位

> **"团队里最不显眼，但最不能少的那个人。"**

记忆流派不抢人头、不打最高伤害。它做的是：
- 让烈焰人闭嘴
- 让女巫变成木桩
- 让监守者的声波变成你的武器
- 让整支队伍从怪群里活着走出来

## 二、强度曲线

| 阶段 | 玩家状态 | 强度 | 说明 |
|---|---|---|---|
| **解锁后 0-2 小时** | 只有忆矢、遗忘、碎忆 | **弱** | 伤害低、忆格少（3 格）、没有装备。这个阶段玩家最容易弃坑 |
| **2-10 小时** | 拿到写入三件套 + 失忆 | **中** | 开始体会到"剥夺能力"的乐趣。忆格管理成为主要玩法 |
| **10-30 小时** | 凑齐 3 件法袍 + 权杖 | **中高** | 4 格忆格 + 共鸣加成开始成型。可以稳定打出连招 |
| **30-60 小时** | 全套法袍 + 多个 Epic 法术 | **高** | 5 格 + 100% 共鸣加成。既视感 + 认知崩坏是主要输出 |
| **60 小时以上** | 收集永久记忆 + Legendary 法术 | **很高** | 拥有多种永久特性，忆海 + 千忆归一可以打出 200+ 伤害 |

### 关于"前 2 小时很弱"的问题

这是**有意的**。记忆流派是一个"理解成本换强度"的流派。但为了避免玩家弃坑，需要三个缓冲：

| 缓冲机制 | 说明 |
|---|---|
| 忆碑保底 | 第一座忆碑必定解锁一个 Common 法术 |
| 拾忆匕首便宜 | 2 忆晶就能做，让玩家快速获得"有用感" |
| 遗忘/失忆很强 | 即使伤害低，玩家也能立刻体验到"关掉怪物"的爽感 |

> **核心原则**：让玩家在"打不出伤害"的阶段，也能感受到"**我在做别人做不到的事**"。

## 三、与九大学派的逐一对比

| 学派 | 记忆流派 vs 它 |
|---|---|
| **火 Fire** | 火是纯伤害。记忆流派的 DPS 只有火的 60-70%。但记忆流派能让火焰人打不出火球 |
| **冰 Ice** | 冰是减速控制。记忆流派的控制是"剥夺能力"，比减速更彻底但更短。冰的控制稳定，记忆的控制是间歇性的 |
| **雷 Lightning** | 雷是爆发。记忆流派没有可比的爆发（除非囤满忆格）。雷可以连发，记忆流派必须准备 |
| **神圣 Holy** | 神圣是治疗与增益。记忆流派**没有任何治疗手段**，它的生存靠"偷"。两者互补性最强 |
| **末影 Ender** | **最需要区分的学派**。末影有传送、有反制。记忆流派能"偷"末影人的传送，但距离更短（8 格 vs 16 格）、且要占忆格。反制关系：末影的 Counterspell 可以打断记忆法术，且会清空正在写入的忆格 |
| **血 Blood** | 血是吸血与亡灵。完全不重叠。血是"消耗自己换力量"，记忆是"消耗敌人换力量" |
| **咒法 Evocation** | 咒法召唤生物。记忆流派用「走马灯」复现技能。区别：**不召唤，只复制**。咒法需要生物存活，记忆流派需要生物"用过技能" |
| **自然 Nature** | 自然是中毒与减益。记忆流派的减益是"能力剥夺"，机制完全不同 |
| **邪术 Eldritch** | 邪术是宇宙与虚空，神秘且稀有。记忆流派是"知识考古"，也稀有。两者气质接近（都是"古老力量"），但视觉和机制完全不同 |

### 互补性分析

| 组合 | 效果 |
|---|---|
| **记忆 + 神圣** | 记忆削弱敌人，神圣治疗队友。完美的支援二人组 |
| **记忆 + 火/雷** | 记忆用失忆把敌人定住，火/雷打输出。记忆流派的"辅助输出"定位 |
| **记忆 + 末影** | 两个都有"信息/机动"属性，但机制不冲突。末影负责位移，记忆负责削弱 |
| **记忆 + 血** | 记忆偷免疫，血吸血。生存能力拉满 |

> **记忆流派的最佳位置是"第二输出位"**——不是主 DPS，而是负责拆解机制、创造输出窗口的那个人。

## 四、反制关系

### 记忆流派克制谁

| 被克制对象 | 原因 |
|---|---|
| **高威胁单体怪**（监守者、唤魔者、女巫、烈焰人） | 这些怪的全部强度都建立在"特殊能力"上，而记忆流派专门剥夺能力 |
| **高频投射物敌人**（骷髅、烈焰人、掠夺者） | 失忆 + 遗忘可以直接关掉它们的远程输出 |
| **召唤型敌人**（唤魔者、幻术师） | 失忆可以打断召唤循环 |
| **需要药水增益的敌人**（女巫） | 失忆让她既不能喝药也不能扔药 |

### 谁克制记忆流派

| 克制者 | 原因 |
|---|---|
| **末影的 Counterspell** | 可以打断记忆法术，且**会清空正在写入的忆格**。这是最合理的克制——"被打断 = 记忆丢失" |
| **高爆发单体怪**（凋灵、末影龙） | 记忆流派的准备时间很长，高爆发会打断准备 |
| **高频攻击的怪群** | 集体遗忘有 40 秒冷却，无法连续使用。怪群持续压制会让记忆流派来不及准备 |
| **任何免疫控制的 Boss** | 虽然 BOSS 免疫遗忘，但仍有"降攻 20%"的替代效果，所以不算完全克制 |

### 反制关系总结图

```
       记忆流派
          │
   克制 ──┼── 被克制
          │
   ┌──────┴──────┐
   │             │
高威胁单体怪    末影(Counterspell)
召唤型敌人      高爆发单体怪
高频投射物      高频怪群
```

## 六、可能的失衡点与预案

| 潜在失衡 | 表现 | 预案 |
|---|---|---|
| **千忆归一 + 忆海组合过强** | 忆海（+3 格）+ 忆格扩张（+4 格）+ 碎忆（+1 格）= 13 格 × 25 = 325 伤害 | 限制"临时忆格"不能被千忆归一消耗；或给千忆归一设一个伤害上限（例如 200） |
| **走马灯复现监守者声波过强** | 监守者声波是模组最高单体伤害之一 | 给复现的技能设一个威力系数（例如 60%），不让玩家 1:1 复现 |
| **质忆偷到飞行/传送后逃课** | 玩家用偷来的能力跳过地形挑战 | 所有偷来的能力**持续时间短**（30 秒），且不能叠加；传送距离短于末影学派 |
| **痛忆被滥用** | 玩家故意站在岩浆里刷伤害 | 伤害上限 60% 最大生命；且岩浆伤害会被上限截断 |
| **集体遗忘变成"无脑逃跑键"** | 玩家遇到任何危险就放 | 40 秒冷却；且敌人 6 秒后会立刻重新索敌 |
| **遗忘对 Boss 无意义** | 玩家觉得 Boss 战用不上 | 提供"降攻 20%"的替代效果，保留价值 |
| **忆碑刷法术** | 玩家找到一座遗迹反复读 | 忆碑对每个玩家只能读一次 |
| **拾忆匕首自动写入太方便** | 玩家不用质忆了 | 自动记忆有效期只有 60 秒；且必须有空忆格 |
| **永久记忆占格子太亏** | 玩家不愿意用记忆掠夺 | 满级记忆掠夺让永久记忆**不计入共鸣惩罚** |

## 七、与其他模组的兼容性平衡

| 场景 | 影响 | 建议 |
|---|---|---|
| 玩家装了"更多生物"类模组 | 遗忘/窃取走通用降级方案 | 提供数据包接口，让整合包作者补充映射表 |
| 玩家装了"更多法术"类模组 | 术忆可以记录其他模组的法术（如果它们走铁魔法 API） | 需要测试；若不兼容则术忆只记录记忆学派法术 |
| 玩家装了"生命值翻倍"类模组 | 痛忆上限（60% 最大生命）会自动放大 | 这是合理的，无需调整 |
| 玩家装了"难度提升"类模组 | 怪物攻击力提升 → 痛忆收益提升 | 这是**正向协同**，无需调整 |
| 玩家装了"Boss 增强"类模组 | Boss 免疫遗忘可能导致流派在 Boss 战中变弱 | 建议在配置中提供"Boss 是否免疫遗忘"的开关 |

## 八、设计红线（不可妥协的三条）

| 红线 | 理由 |
|---|---|
| **记忆流派不能有最高的 DPS** | 一旦它成为输出之王，它的"辅助/控制"定位就失去了意义，其他学派也会被边缘化 |
| **BOSS 必须免疫"剥夺"** | 否则整个游戏的 Boss 设计会被一个流派摧毁 |
| **忆格必须有硬性上限** | 否则共鸣机制退化成纯数值堆叠，流派的灵魂（取舍）就没了 |
