# 核心机制 · 遗忘与能力映射

> 本文是记忆流派**最有辨识度**的部分——让敌人忘记怎么战斗，或者把它的本事偷过来。
> 上级文档：[README 总览](README.md)　｜　相关文档：[01 忆格系统](01_核心机制_忆格系统.md)、[03 法术总表](03_法术_总表与设计准则.md)

---

## 一、为什么"遗忘"是这个流派的招牌

其他学派打怪的方式是：**把血条打空**。
记忆流派打怪的方式是：**把血条旁边那个"它会什么"的清单打空**。

这两种思路带来的体验完全不同：

- 面对烈焰人，火学派玩家想的是"我要打出足够高的伤害"。
- 面对烈焰人，记忆流派玩家想的是"**我不让它喷火**，然后走进去慢慢打"。

后者带来的是一种**掌控感**——不是"我比你强"，而是"**我比你先知道你会做什么，并且我把它拿走了**"。这是整个模组里独一份的体验。

## 二、遗忘的三个层级

| 层级 | 代表法术 | 效果强度 | 持续时间 | 作用范围 |
|---|---|---|---|---|
| ~~**遗忘** Forget~~ | ~~`遗忘`~~ **已删除** | ~~随机移除 1 个 AI 行为~~ → 并入「失忆」 | ~~6 秒~~ | ~~单体~~ |
| **失忆** Amnesia | `失忆` | 清除仇恨 + 禁用全部特殊能力 | 4 秒 | 单体 |
| **集体遗忘** Mass Amnesia | `集体遗忘` | 所有敌人忘记你存在、停止攻击 | 6 秒 | 半径 8 格 |
| **遗忘诅咒** Curse of Oblivion | `遗忘诅咒` | 持续领域，区域内敌人遗忘随机能力 + 减伤 15% | 8 秒 | 半径 5 格 |

### 2.1 ~~「遗忘」——随机移除一个 AI 行为~~ 已删除（2026-09-18）

> 这一档（tier 1，单体随机摘一项）原本由法术「遗忘 Forget」承载，
> 但它与 2.2 的「失忆」**效果太像** —— 都是"从目标身上摘掉能力"，
> 只是一个摘一项、一个摘全部 + 眩晕，玩家在实战里分不清该用哪个。
> 所以删掉了弱的那一个：**失忆**提到中阶 Rare，独占遗忘系的单体起手位。
>
> ⭐ **tier 1 这个机制本身没有消失**：遗忘诅咒的领域每 40~20 tick 走的仍然是
> tier 1（见 2.4），`oblivion.forgetSeconds` 配置项也照旧有效。
> 被删掉的只是"把它做成一个独立法术"这件事。

### 2.2 「失忆」——彻底关掉它

这是最有价值的一层。「失忆」期间，目标的**所有特殊能力被禁用**：

- 烈焰人无法发射火焰弹
- 末影人无法传送
- 女巫既不能投掷药水也不能喝药水
- 骷髅无法射箭
- 潜影贝无法发射追踪弹
- 唤魔者无法召唤尖牙与恼鬼
- **监守者无法释放声波攻击**（这是流派的高光时刻）

同时：
- 目标**清除对你的仇恨**（不再把你作为攻击目标）
- 目标在失忆生效的前 1.5 秒内**停止移动**（"发呆"状态）

> **注意**：失忆不会让敌人变成友军，也不会让它们完全无害——它们仍会用普通近战攻击其他靠近的目标。它的作用是**拆解机制**，而不是"无敌"。

### 2.3 「集体遗忘」——战术级救援

- 半径 8 格内的**所有敌对生物**立即忘记你的存在：
  - 清空它们的攻击目标
  - 6 秒内不再主动攻击任何玩家
  - 期间它们会缓慢游荡（"迷茫"状态）
- **不消耗目标的任何能力**——只是让它们短暂忘记要打谁。
- 用途：
  - 队友快死了 → 集体遗忘 → 怪物散开 → 救援
  - 被围殴时强制脱战
  - 配合「认知崩坏」打一轮无风险的爆发

### 2.4 「遗忘诅咒」——持续压制

- 在目标位置生成一个半径 5 格、持续 8 秒的诅咒领域。
- 领域内的敌人：
  - 每 2 秒**随机遗忘一个能力**（可叠加，最多同时遗忘 3 个）
  - 造成的伤害 **-15%**
- 离开领域后效果持续 3 秒后消失。
- 这是**唯一能同时压制多个敌人**的遗忘手段，适合放在怪物聚集处。

## 三、遗忘的判定规则

| 规则 | 内容 |
|---|---|
| **对玩家** | **完全无效**。遗忘类法术对玩家不产生任何效果（保护 PVP 体验） |
| **对 BOSS** | **完全免疫**。末影龙、凋灵、监守者（视为 BOSS 级）不受遗忘影响 |
| **对召唤物** | 有效。但移除的行为是"跟随召唤者"，效果等同于让它原地发呆 |
| **对被动生物** | 有效但无意义（改为 -20% 移速） |
| **对精英怪** | 有效，但持续时间减半 |
| **叠加规则** | 同一层级不叠加（取最长持续时间）；不同层级可共存 |
| **与反制法术的关系** | 末影的 `Counterspell` 可以打断正在施放的遗忘法术 |

### 为什么 BOSS 免疫

如果 BOSS 能被遗忘，整个游戏最有设计感的 Boss 战会变成"按一下键然后站着砍"。这不是平衡问题，是**设计尊严问题**。

对 BOSS 的替代效果：

| 遗忘类法术 | 对 BOSS 的实际效果 |
|---|---|
| `遗忘` | BOSS 攻击力 **-15%**，持续 6 秒 |
| `失忆` | BOSS **停止攻击 1.5 秒**（打断一次攻击动作） |
| `集体遗忘` | BOSS **受伤 +15%**，持续 6 秒 |
| `遗忘诅咒` | 领域内 BOSS **攻击速度 -20%** |

> 这样既保留了记忆流派在 Boss 战中的价值（它是少数能"削弱 Boss"的流派），又不会摧毁 Boss 设计。

## 四、生物能力映射表（三张表）

这是本流派**工作量最大、也最出彩**的部分。要让"遗忘"和"窃取"真正好玩，必须为尽可能多的生物建立清单。

三张表分别对应三种玩法：

- **表 A · 可遗忘的能力** → 用于「遗忘」「失忆」「遗忘诅咒」
- **表 B · 可窃取的特性** → 用于「写入 · 质忆」「记忆掠夺」
- **表 C · 可复现的技能** → 用于「走马灯」

### 表 C · 可复现的技能清单（走马灯）

「走马灯」的规则是：**目标最近使用过的技能，你也能用一次**。

| 生物 | 可复现的技能 |
|---|---|
| 烈焰人 | 小火球（直线投射物，中等伤害 + 点燃） |
| 恶魂 | 大火球（可被击回的慢速火球） |
| 末影人 | 瞬移（16 格） |
| 女巫 | 投掷药水（随机负面药水） |
| 骷髅 | 箭矢（精准直射） |
| 潜影贝 | 追踪弹（自动锁定） |
| 唤魔者 | 尖牙陷阱（地面连续尖牙） |
| 幻术师 | 召唤分身（2 个无法被攻击的幻影） |
| 守卫者 / 远古守卫者 | 激光射线（持续照射） |
| 雪傀儡 | 雪球（击退） |
| 岩浆怪 | 跳跃（高跳） |
| 幻翼 | 俯冲（向前冲刺 + 伤害） |
| 溺尸 | 三叉戟投掷 |
| 掠夺者 / 猪灵 | 弩箭 |
| 疣猪兽 | 冲撞 |
| 山羊 | 冲撞 |
| 监守者 | **声波冲击**（远程穿透伤害，**这是最强的复现技能**） |
| 末影龙 / 凋灵 | **不可复现**（避免玩家复现凋灵之首） |

**规则细节**：

- 「走马灯」需要目标**在最近 10 秒内使用过**该技能，否则复现失败（法力照常消耗）。
- 复现的技能**以铁魔法法术的形式执行**，因此受到 `memory_spell_power` 加成，也受到目标的 `memory_magic_resist` 抵抗。
- 复现的技能**没有冷却**，但「走马灯」法术自身有冷却。
- **对玩家无效**（不能复现玩家的法术）。
- 复现监守者的声波是流派最强单点输出手段——这也是记忆流派唯一能打出高伤害的途径，代价是你得先让监守者活着放一次。

## 五、遗忘的战术应用案例

### 案例 1 · 烈焰人刷怪笼

**问题**：烈焰人刷怪笼让人无法靠近，火焰弹持续输出。

**记忆流派解法**：
1. 对最近的烈焰人施放 `失忆` → 它 4 秒内不能喷火
2. 趁这 4 秒冲进去用 `写入 · 质忆` 偷走它的**火焰免疫**
3. 释放质忆 → 你 30 秒内不怕火
4. 直接站进刷怪笼里，用近战清场

> 这是记忆流派最经典的"以彼之道还施彼身"。

---

### 案例 2 · 女巫塔

**问题**：女巫不断喝药水回血、扔负面药水，非常难杀。

**记忆流派解法**：
1. `失忆` → 女巫 4 秒内既不能喝药也不能扔药
2. 在这 4 秒内打出爆发
3. 重复直到击杀

> 女巫是记忆流派最擅长的目标——她的全部强度都建立在"能力"上，而记忆流派专门剥夺能力。

---

### 案例 3 · 监守者（高光时刻）

**问题**：监守者的声波攻击几乎无法躲避，伤害极高。

**记忆流派解法**：
1. 被监守者发现后，立刻 `失忆`
2. 监守者 4 秒内无法释放声波，并停止移动 1.5 秒
3. 用 `走马灯` 复现它**刚才那一次声波** → 你自己打出一发穿透伤害
4. 循环

> 这是整个流派最"爽"的瞬间：**你把它最可怕的武器变成了你的武器。**

---

### 案例 4 · 末影人农场

**问题**：末影人会传送躲开攻击，很难稳定命中。

**记忆流派解法**：
1. 先 `遗忘` 赌一个"移除传送"（成功率约 1/3，因为它有传送、瞬移闪避、搬方块三个行为）
2. 或用 `失忆` 直接封掉 4 秒
3. 也可以 `写入 · 质忆` 偷走传送——**这样你自己也能传送了**

> 记忆流派是唯一能"把末影人的传送装进自己口袋"的流派。

---

### 案例 5 · 团队救援

**问题**：队友被一群怪物围住，血量见底。

**记忆流派解法**：
1. 冲进怪群中心，施放 `集体遗忘`
2. 半径 8 格内所有怪物立即停止攻击，缓慢游荡 6 秒
3. 队友趁机撤退 / 补血

> 这是记忆流派最强的团队价值。它没有治疗法术，但能"制造一个没有危险的 6 秒"。

## 六、映射表的扩展与维护原则

### 优先级

不是所有生物都值得做完整映射。建议按以下优先级推进：

| 优先级 | 生物类型 | 理由 |
|---|---|---|
| **P0（必须做）** | 烈焰人、女巫、末影人、骷髅、蜘蛛、苦力怕、监守者 | 出现频率高，能力辨识度强 |
| **P1（应该做）** | 恶魂、岩浆怪、潜影贝、唤魔者、幻术师、掠夺者、猪灵、凋灵骷髅 | 有明确"特殊能力" |
| **P2（可以做）** | 尸壳、溺尸、幻翼、疣猪兽、山羊、铁傀儡、雪傀儡 | 能力较弱，锦上添花 |
| **P3（可降级）** | 纯被动生物、其他模组生物 | 统一走"通用降级"：给一个固定的移速减益 |

### 通用降级方案

对于**没有单独映射**的生物（包括其他模组添加的生物），统一采用降级规则：

- `遗忘` → 该生物受到的伤害 +10%，持续 6 秒
- `失忆` → 该生物停止攻击 1.5 秒
- `写入 · 质忆` → 写入"通用记忆"：释放时获得 30 秒的微弱速度提升（+10%）
- `走马灯` → 复现失败，返还 50% 法力

> 这样即使玩家装了别的模组，记忆流派也不会完全失效。

### 与其他模组的兼容

- 记忆流派**天然兼容**其他模组添加的生物——所有效果走的是"移除 AI 行为"和"事件拦截"，不依赖具体生物类型。
- 对于有自定义 AI 的生物，`遗忘` 会走通用降级；但 `失忆` 的"禁止特殊能力"可能失效（因为不知道它有什么能力）。
- **建议**：在模组配置中提供一份"用户可编辑的能力映射表"（数据包形式），让整合包作者可以自己补充。
